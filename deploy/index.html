Halogen lightbox: light field across the test plane, 19 to 124 VAC

Built from the 77-node map (A1 to K7, 50 mm pitch, F4 at the geometric centre) measured at every variac level. Irradiance has the 0.23 W/m² zero offset removed. Nothing is drift-corrected: each pass's reference drift is carried as an uncertainty instead. There is no curve fitting: every number comes from the measured nodes.

The exponent n in the table is the local slope between neighbouring levels, max ∝ VAC^n; a level that is off shows up as a jump in n on both sides of it.

    05

    Average irradiance and lux over a panel

    Panel centred on F4. Width runs along columns A to K, length along rows 1 to 7. The measured map is interpolated bilinearly between nodes and averaged over the rectangle on a 5 mm grid. The first calculator works at the measured VAC levels only. The second runs the other way: give it a required irradiance and it finds the VAC by interpolating between the two measured levels either side. At most 500 × 300 mm, the measured extent.

    Method and files

    Everything on this page is computed by src/calibration_report.py from the campaign folder you point it at, so a new campaign needs no code change.

    python src/calibration_report.py calibration/<campaign-folder>
python src/calibration_report.py calibration/<campaign-folder> --vac 54 --panel 200x150
python src/calibration_report.py calibration/<campaign-folder> --target-irr 100 --panel 200x150

    Outputs go to <campaign>/analysis/report/: report.html (this page, offline), report_data.json (its data), calibration_report.xlsx (all tables, raw values, gray 0 to 255 matrices with cell shading), and one grayscale heatmap PNG per level and quantity.
